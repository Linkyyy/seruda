# 风野纪行 · WINDWARD

一个原创的 GBA 像素风 2D 横版探索游戏。在十片不同地貌的区域之间旅行，攀爬、滑翔、战斗、采集与烹饪，运用五种符文解开十五座神庙的机关，最终前往遗迹挑战守卫。

画面由 Canvas 实时绘制，音乐与音效由 Web Audio 合成。角色、场景、地图、神庙与配乐均为原创实现，无需下载外部素材、字体或音频文件。

## 启动

需要 Node.js 20 或更新版本，无第三方运行依赖，无需执行 `npm install`。

```bash
cd /workspace/seruda
npm run dev
```

开发服务器默认端口为 `3000`，通过云环境的应用访问入口打开对应端口。浏览器需要支持 Canvas 与 ES modules；localStorage 用于保留进度，存储被禁用时也可以游玩。请通过 HTTP 服务器运行，避免直接用 `file://` 打开 HTML。

```bash
npm test          # 执行现有自动化测试
npm run build    # 生成 dist/ 静态发布文件
npm run preview  # 在端口 4173 预览构建产物
```

## 发布到 Vercel

在 Vercel 导入 GitHub 仓库 `Linkyyy/seruda`，框架选 Other。仓库的 `vercel.json` 已指定构建命令 `npm run build` 和输出目录 `dist`，安装命令使用锁文件 `npm ci`。不需要应用环境变量或后端服务。

如果使用 Vercel CLI，先通过 Vercel 官方登录或安全配置部署令牌，再在仓库根目录运行 `vercel --prod`。不要将令牌提交到 GitHub。

## 操作

| 按键 | 动作 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 左右移动 |
| `Space` | 跳跃；在空中再次按下展开滑翔翼 |
| `W` / `↑` | 靠近可攀爬物时攀爬 |
| `Shift` | 冲刺，消耗体力 |
| `J` | 近战攻击 |
| `K` | 射箭，消耗箭矢 |
| `E` | 与附近物体互动、进入神庙、领取祭坛奖励 |
| `R` | 切换符文 |
| `F` | 使用当前符文 |
| `C` | 在营火附近烹饪 |
| `Q` | 食用料理恢复生命 |
| `M` | 打开世界地图 |
| `I` | 打开行囊 |
| `H` | 查看操作帮助 |
| `Escape` | 暂停 / 返回 |

触屏设备可以使用页面提供的方向与动作按钮。移动与动作可同时按住；收起弹窗后继续探索。音乐默认关闭，点击页面上的声音按钮后启用。

### 手机与平板

手机点击开始后自动进入沉浸游戏模式，不要求浏览器支持全屏 API。右上角收起图标可以退出并暂停；点击继续会回到游戏。竖屏视野会随屏幕比例放大并跟随角色，横屏提供更宽视野，旋转屏幕保留进度。

- 左侧左右移动，按住攀爬、冲刺；右侧跳跃、攻击、射箭、符文和交互。空中再点一次跳跃展开滑翔翼。
- 支持多指同时操作；长按攻击或射箭连续出招。在按键外松手、触控取消或应用切到后台会清除按键状态，避免角色持续移动。
- 下方可以切换符文、食用料理或苹果、在营火烹饪与制箭；顶部地图与行囊入口始终可用。
- 界面考虑刘海屏、底部手势区和浏览器可见高度。触控目标至少 44 像素，地图与行囊弹窗可以独立滚动。

## 探索与进度

- 十张野外地图首尾相连。走到区域边界可进入下一片地貌；世界地图可以传送到已经到访的地区。
- 体力影响冲刺、攀爬与滑翔，合理落地休息再继续前进。受伤后可以吃料理恢复生命。
- 击败敌人、打开宝箱与探索场景可以取得资源。在营火旁按 `C`：优先消耗两枚苹果烹饪一餐；苹果不足时，消耗两份木材制作八支箭。料理恢复两颗心；没有料理时，按 `Q` 会改吃苹果，恢复半颗心。
- 十五座神庙分别围绕风、磁力、时停、爆破与火焰符文设计。进入神庙后阅读提示，靠近对应机关，切换到所需符文并使用，然后抵达祭坛互动领取灵珠。
- 每完成四座神庙，生命上限增加一颗心。领取神庙奖励时生命会回满，并补充四支箭；完成全部十五座神庙后，前往苍穹王庭挑战最终守卫。

进度自动保存在当前浏览器的 localStorage 中，包括探索与神庙进度。刷新页面后可以继续冒险。更换浏览器、访问来源或清理站点数据会使该存档不可用；存档不会上传到服务器。重新开始前请确认页面上的提示。

## 目录

```text
index.html       页面与界面结构
styles.css       响应式界面样式
server.mjs       无依赖静态文件服务器
src/main.js      界面与游戏事件连接
src/game.js      物理、战斗、交互、进度与存档
src/world.js     十张地图与十五座神庙的数据与工厂
src/render.js    Canvas 像素美术、动画与特效
src/audio.js     原创合成配乐与音效
tests/           自动化验证
```

这是单人本地浏览器游戏。地图、战斗、资源与机关系统均在客户端运行，不需要账号、API 密钥或后端数据库。
